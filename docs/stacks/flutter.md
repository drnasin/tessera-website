# Flutter Stack (Mobile + Web App)

Tessera's AI project generator builds cross-platform mobile applications from a single codebase — targeting iOS, Android, and Web simultaneously.

## What Gets Generated

- Flutter project with Riverpod state management
- go_router navigation
- Material 3 theme
- Feature-based folder structure
- Widget and unit tests
- Platform-specific build guidance
- SETUP.md with deployment instructions

## When AI Picks This Stack

Tessera recommends Flutter when you describe:
- A mobile app for iOS and/or Android
- A delivery app, fitness app, POS system, or similar
- Cross-platform requirements (one codebase, multiple platforms)
- The need for native performance on mobile devices
