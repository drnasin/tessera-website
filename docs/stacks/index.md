# Technology Stacks

AI picks the best stack based on your project requirements. All stacks use principle-based AI prompts — the AI reasons about what to build rather than following a recipe.

| Stack | Best for |
|---|---|
| [Laravel + Filament](laravel) | Websites, CMS, e-commerce, admin panels |
| [Node.js](nodejs) | APIs, SaaS, real-time apps |
| [Go](go) | High-performance backends, microservices |
| [Flutter](flutter) | Mobile apps (iOS + Android + Web) |
| [Static](static) | Landing pages, portfolios, event pages |
