# Static Site (HTML + Tailwind)

Simple landing pages without a backend — deploy to Netlify, Vercel, or GitHub Pages.

## What Gets Generated

- HTML5 + Tailwind CSS + Alpine.js
- Vite for build
- SEO optimized (meta, OG tags, JSON-LD)
- Contact form (Formspree or Netlify Forms)
- Netlify + Vercel deploy configs
- SETUP.md with deployment instructions

## When AI Picks This

- Simple landing page, portfolio, event page
- No backend needed
- "Just a website" with no dynamic content
- Quick one-off pages
