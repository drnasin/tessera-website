# Static Stack (HTML + Tailwind CSS)

Tessera's AI project generator builds simple, fast landing pages without a backend — ready to deploy on Netlify, Vercel, or GitHub Pages in minutes.

## What Gets Generated

- HTML5 + Tailwind CSS + Alpine.js
- Vite for build and development
- SEO optimized (meta tags, OG tags, JSON-LD structured data)
- Contact form (Formspree or Netlify Forms)
- Netlify + Vercel deploy configurations
- SETUP.md with deployment instructions

## When AI Picks This Stack

Tessera recommends a static site when you describe:
- A simple landing page, portfolio, or event page
- No backend or database needed
- "Just a website" with no dynamic content
- Quick one-off pages that need to go live fast
